## 📋 课程简介

Stanford CS336: Language Modeling from Scratch 是一门从零开始构建大语言模型的实践课程。涵盖从 Tokenizer 到 Transformer 架构，从训练系统到推理优化的完整 pipeline，深入理解现代 LLM 的每一个环节。
